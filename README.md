# Area Lab

Instant geometry area calculator in the browser.

| Shape | Inputs |
|-------|--------|
| Rectangle | width × height |
| Triangle | base × height ÷ 2 |
| Circle | π r² |
| Trapezoid | (a + b) / 2 × height |

## Run

Open `index.html`.

## Files

| File | Role |
|------|------|
| `index.html` | Form UI |
| `app.js` | Formulas |
| `styles.css` | Dark lab theme |
